# viewer

Local dashboard for this experiment's long-horizon search: live rollouts while a
generation runs, and the search's record after it. Read-only and stateless —
every request re-reads the files, nothing is cached, and it never runs eval,
promote, gate or adopt.

```bash
uv run uvicorn app:app --port 8000     # http://localhost:8000, refreshes every 30 s
uv run python smoke.py                 # every endpoint 200 with the expected shape
uv run python smoke.py --watch 10      # poll /api/status, print what changed
python check_literals.py               # no measured value is hardcoded in the source
```

## Fixtures

`fixtures/` holds a small `state/` and `outputs/` written from this
experiment's code before it first ran, covering every verdict and a failed gate.
`fixtures/SOURCES.md` records where in the code each field comes from. To run
the viewer on them without a search:

```bash
python3 touch_fixtures.py              # git does not keep mtimes; this restores the fixtures' order
VIEWER_EXPERIMENT_ROOT=fixtures uv run uvicorn app:app --port 8000
uv run python smoke.py --fixtures fixtures   # also checks runs and candidates come in that order
```

Generated by the `viewer-scaffold` skill. **`experiment.py` is the only file
that knows anything about this experiment** — the mapping from its state dir
onto the spine the dashboard renders. `app.py` and `static/index.html` are the
skeleton and are the same in every generated viewer; when the state layout
changes, change `experiment.py`.

| section | source |
|---|---|
| live cards, log tail | `experiment.DOCKER_IMAGE`, `PROCESS_PATTERN`, `LOG_GLOB`, `GENERATION_RE` |
| runs → rollouts → trace | `experiment.runs()`, `rollouts()`, `rollout_trace()` |
| reward curve, gate | `experiment.promotions()`, `gate()` |
| candidates | `experiment.candidates()` |
| everything else | `experiment.extras()`, rendered from the blocks' own descriptions |
| section legends | `experiment.notes()` — prose only, no digits; figures are interpolated from files |

Every number on the page is read from a file at request time. Nothing measured
is ever written into the source — `check_literals.py` is what keeps that true,
and a viewer that fails it is not a viewer, it is a screenshot.
